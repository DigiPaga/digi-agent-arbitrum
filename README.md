# DigiPaga Robotics\n\n## Arbitrum Open House Singapore Buildathon Project\n\nDual-rail marketplace for Agentic Commerce (AI agents buying via x402) and Human Discovery (interactive robotics gadget map).\n\n### Tech Stack\n- **Smart Contracts**: Foundry, Solidity 0.8.20, ERC-8004 (Agent Identity)\n- **Backend**: Node.js, Express, x402 payment middleware\n- **Frontend**: Next.js 14, Tailwind CSS, Wagmi, ZeroDev (Account Abstraction)\n- **Chains**: Arbitrum Sepolia, Robinhood Chain Testnet\n\n### Quick Start\n1. `cp .env.example .env`\n2. `cd contracts && forge install && forge build`\n3. `cd ../x402-server && npm install && npm run dev`\n4. `cd ../web && npm install && npm run dev`
